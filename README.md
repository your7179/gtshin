# gtshin.com - Linux Mint Japanese Guide

Jekyll site for GitHub Pages.

## Folders

| Path | Purpose |
|---|---|
| `_config.yml` | Site settings (title, URL, GA4 / AdSense IDs) |
| `_guides/` | Articles. File name: `044-linux-mint-install-guide.md` |
| `images/044/01.png` | Article images (one folder per article number) |
| `pages/` | Category pages and footer pages |
| `_data/navigation.yml` | Header and footer menus |
| `_data/categories.yml` | Categories and subcategories (order) |
| `_layouts/`, `_includes/` | HTML templates |
| `assets/` | CSS, JavaScript, icons, OGP image |
| `_templates/` | Article template (not published) |
